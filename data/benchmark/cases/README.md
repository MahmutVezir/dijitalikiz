# Confirmatory case directory

Only cases that pass the pre-registered intake criteria belong here.

Each JSON case must conform to the ResearchCase schema and include independently established ground truth. Pilot cases remain in data/pilot unless their inclusion is explicitly justified before the confirmatory dataset is frozen.

Do not add a case because a model produced a favorable answer.

After freezing, do not alter evidence, CCDG edges, or ground truth without recording a protocol deviation.
